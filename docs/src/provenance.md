# Provenance

any-gpu maintains a full dated record of every design decision, shipping commit, and human/AI attribution. This is not generated spaghetti — it is a pilot-in-command project with documented direction at every step.

Two documents form the provenance record:

## Timeline of Invention

[Timeline of Invention](timeline.md) — dated, commit-level record of what was built, when, and why. Every entry maps to real git commits. Run `git log --oneline` to verify.

Covers: Sprint 1 (initial wgpu backend) through Sprint 7 (fused SDPA, tokenizer, LLM inference stack, serve runtime). 256 tests across 4 GPUs.

## Proof of Artifacts

[Proof of Artifacts](proof.md) — concrete evidence that this project works, ships, and is real. Architecture diagram, op catalog, build output table, hardware verification, full benchmark matrices (any-gpu vs CUDA vs MPS), NanoSign, Triple Lens evaluation.

Every benchmark has a reproduce command. Every GPU claim links to a commit. CUDA comparison shows where we lose and by how much.
